# Final Project Running Instructions Evan Smith
## Getting the Data
If you are in the Final-Project-Evanasmi folder, run 'python .\src\get_data.py'
## Cleaning the Data
Once you have run the get_data file, run 'python .\src\clean_data.py'
## Data Analysis
To see the data analysis results, run 'python .\src\analyze_data.py'. There are a lot of results and methods, so prepare for some scrolling. Titles are above each of the results to show what the different stats display.
## Data Visualization
To see the graphs and charts, run 'python .\src\visualize_results.py'. Prepare for a lot of graphs to click through. There may be a slight hesitation after the stats by round graph but wait a moment or two and the stats by pick graph will appear.
